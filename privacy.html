Privacy Policy

Last updated: 20 September 2026

This site collects nothing about you.

This policy covers telosrg.com and telosrg.github.io/telosrg-site (“this site”). It does not cover the individual applications in the portfolio — each of those is a separate project and carries its own policy where one applies.

What we collect

Nothing. This site is a set of static HTML and CSS files. There is no JavaScript, no analytics, no advertising or re-marketing pixels, no cookies, no local storage, no contact form, and no account system. We have no database in which to put information about you, and we do not set out to identify visitors.

What our host sees

This site is served by GitHub Pages. Like any web host, GitHub receives standard request data — including your IP address and user-agent string — in order to deliver the page to you. That collection is GitHub's, governed by the GitHub Privacy Statement, and we neither receive nor retain those logs.

The site also loads one image, the organization mark, directly from GitHub's avatar servers, which means your browser makes a request to GitHub to fetch it. Everything else on the page is served from this site.

If you email us

If you write to contact@telosrg.com, we keep that message and your address for as long as it takes to answer you and to keep a record of the conversation. We use it to reply, and for nothing else. We do not sell it, rent it, or add it to a mailing list.

External links

This site links out to third-party sites, chiefly GitHub repositories. We are not responsible for the content or privacy practices of any site we link to.

Your rights

Because we hold nothing on visitors, there is generally nothing to request or delete. If you have emailed us and want that correspondence removed from our records, write to contact@telosrg.com and we will delete it.

Changes

If this policy changes, the revised version is posted here with a new “last updated” date. There is no archive of prior versions on the site; the full history of this file is public in the site's repository.
